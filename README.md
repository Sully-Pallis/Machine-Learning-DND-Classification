# Machine Learning Classification Model

A series of machine learning models that attempt to identify the class of a Dungeons & Dragons character based on the stat blocks from their character sheet. I used a database with over 1 million individual character's stats, and multiple types of models.

## Description

The Jupyter notebook outlines my process from cleaning the data to deciding on one model that provides the best results. The models each take a sample of the dataset due to the fact that the size of the original csv is over 1 million lines. It then determines based on the stats in each of the six categories correlates to the class of the character. 

### Dependencies

You will need either Jupyter Notebook to view the already run models saved there, as well as my overall process, or Spyder or some similar IDE. Additionally, in order to run the models yourself you will need the CSV file.

### Installing

You can download the files anywhere that Jupyter or Spyder can access them, from this repository. An important thing to note on the Python file is that it currently has everything except the Random Forest model commented out, to see all the results you will need to remove the comments.

### Executing program

Jupyter Notebook:
-Simply download the file and open it inside of Jupyter Notebook, everything should be already run and ready to be viewed.

Python/Spyder:
-Download the file and move it to an accessible location.
-Open the file inside Spyder and remove comments from the models you wish to view or add them to those you do not wish to see.
-Hit the run arrow
